# bookie_buddy_ui

Shared, purely-visual layer for Bookie Buddy's mobile and web apps — design
tokens, enum→color/icon mappings, and deterministic data→bitmap rendering
pipelines. Depends on `bookie_buddy_core`.

First (in-progress) extraction: the thermal-receipt canvas renderer, copied
from the mobile app's `thermal_printer` feature — see `docs/PENDING.md` in
this repo for exactly what's finished vs. still staged for later.
